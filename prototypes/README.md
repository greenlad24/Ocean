# Prototypes

One folder per prototype, kebab-case slug. Standard layout:

```
prototypes/<slug>/
├── GDD.md          # game-designer  — the magic moment
├── ART_BRIEF.md    # art-director   — look, UX, hero shot
├── MARKET.md       # market-scout   — who buys, at what price
├── FINANCE.md      # finance-analyst— margin card, GO/NO-GO, walk-away $
├── build/          # prototype-engineer — runnable slice + README
├── PLAYTEST.md     # playtest-qa    — magic-moment verdict, buyer-readiness
└── PITCH/          # deal-closer    — sell-sheet, deck, outreach, deal-terms
```

Start one by invoking `studio-head`, or run a single specialist directly.
