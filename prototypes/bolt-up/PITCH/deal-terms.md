# BOLT UP — deal terms & negotiation range

*owner: deal-closer + finance-analyst · floors from FINANCE.md*

## Preferred structure (in priority order)

### 1. Burn-rate / pay-per-prototype retainer  ← the goal (highest assurance)
- Publisher covers studio monthly cost (Azur-style after 2–4 prototypes) **or** pays per test/iteration (Supersonic-style: ~$300/test, up to $5k/iteration, $5–10k/mo for hybrid hitting KPIs).
- **Floor:** covered monthly cost **+ 15% margin**; per-iteration floor **$3.6k** (build cost $2.2k + $1.4k margin).
- Non-exclusive where possible (Azur allows this) so we can run multiple publisher relationships.

### 2. Work-for-hire reskin / co-dev to brief
- Fixed-bid per prototype with **20–30% deposit, milestone payments, written acceptance criteria, kill-fee** (these are what push WFH to ~90%+ assurance per the research).
- IP transfers **incrementally with payment**, not all-at-the-end.

### 3. Rev-share publishing (upside only — never the basis for greenlight)
- Accept **50–55% net-to-developer** (CrazyLabs 55% / Homa 50/50 are the market anchors).
- Treat any advance as a bonus; the *scaled hit* is ~1% — never counted toward the assured floor.

## Walk-away lines
- No iterating for free "to prove ourselves" beyond this one already-built sample.
- No deal that assigns IP before payment clears.
- No pure post-launch rev-share with zero advance/retainer as the *only* compensation (that's a lottery ticket, not revenue).

## What we give to close
- The playable, verified-solvable build + hero GIF up front (de-risks them).
- Fast reskin turnaround and a steady prototype cadence (the thing burn-rate publishers actually want).
