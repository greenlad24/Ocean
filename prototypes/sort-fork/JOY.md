# JOY & USP — "Cable Sort: SURGE"

*owners: game-psychologist + ux-designer · the answer to "why does this feel good and why install it?"*

## The problem with v1 (honest)
Plain sort puzzles are **emotionally flat**: a calm, even loop with one tiny pop at the end. No anticipation, no escalation, no climax → **no dopamine arc** → no reason to install over the 400 identical clones.

## The USP (psychology-first)
> **"Untangle the chaos — feel the SURGE."** A sort puzzle re-engineered as a **build-up-and-release machine**: chaining good moves charges a Flow meter, and clearing outlets in quick succession detonates a **Surge** — an escalating, multi-sensory dopamine peak that plain sort games never deliver.

**The principle it exploits:** dopamine fires on *rising anticipation*, then *release*. v1 had a flat line; SURGE adds a rising curve and a climax. That curve is the product.

## The install thesis (the 3-second ad)
The creative shows the **Surge**: the player makes one move, outlets cascade-complete, the Flow meter maxes, and the screen erupts in light + an ascending chord + a coin shower. Caption: *"wait for the surge 😳"*. It stops the thumb because it pairs **oddly-satisfying release** with **anticipation/curiosity** ("how do I make THAT happen?").

## The Joy Map (core loop, second-by-second)
| Beat | Player feels | Dopamine role | Mechanic that produces it |
|---|---|---|---|
| Tap a plug | "responsive, mine" | micro-reward | plug lifts (squash/stretch) + rising pluck tone |
| Valid drop | "yes, progress" | micro-release | snap + bounce + click; Flow meter ticks up |
| Flow rising | "I'm on a roll" | **anticipation (the key beat)** | meter fills, audio pitch climbs, colours saturate, glow intensifies |
| About to complete | "here it comes…" | anticipation gap | the outlet **telegraphs**: pulses/charges ~250ms before payoff |
| Outlet powers on | "YES" | **release**, scaled to Flow | LED ignites, cables snap taut+glow, particle burst, triumphant chord (pitch = combo) |
| 2+ completes fast | "ohh it's chaining!" | escalation | combo counter; each is bigger/brighter/higher |
| Flow maxed → **SURGE** | euphoria | **peak** | screen-fill light pulse, ascending arpeggio, coin shower, slow-mo beat |
| Last outlet (near-win) | tension → relief | Zeigarnik → release | vignette + low drone builds, then resolves on the final clear |
| Win screen | pride + "again" | **peak-end** | designed climax: stars slam in, big chord, variable bonus reveal |

## Engineered-joy systems (what we build, each tied to a principle)
1. **Feedback on EVERY input** (UX: no dead taps) — incl. a *gentle* non-punishing buzz on invalid moves.
2. **Flow meter** — consecutive valid moves (no mistakes, decent pace) charge it; it visibly + audibly escalates → manufactured *anticipation*.
3. **Combo + SURGE** — completing outlets within a short window chains; threshold triggers the peak. *(escalation + variable peak)*
4. **Telegraph** — wind-up before every completion so release has a setup. *(anticipation gap)*
5. **Near-win tension** — drone/vignette when 1 outlet remains → resolved by the clear. *(Zeigarnik)*
6. **Peak-End win** — every level ends on a climax; a **variable bonus** (sometimes 2×/3×) adds surprise. *(peak-end + variable ratio)*
7. **Goal-gradient meta** — "1 building to light up the district!" messaging accelerates motivation near goals.
8. **Front-loaded hook** — level 1 is tuned so a first-time player triggers a Surge within ~20 seconds.

## Ethical guardrail (game-psychologist)
We engineer *delight*, not *compulsion*. Lives regen free; no pay-to-not-lose-progress trap; "double coins" ads are opt-in; no deceptive odds; surprise bonuses are genuinely positive, never loss-framed. If any monetization tilts toward preying on compulsion, it's cut. Engagement ≠ exploitation.

## Self-QA (game-psychologist + ux-designer)
- **These are heuristic hypotheses, not measured dopamine.** Confidence the Surge arc raises *engagement/feel* vs. flat v1: **~70%** (well-grounded in established design — Tetris/match-3 cascades, ASMR puzzles). Confidence it moves real **D1 retention / CPI**: **unproven (~40%)** — requires a real on-device playtest + a CPI A/B test. Stated honestly.
- *What would confirm it:* 20–50 person playtest measuring "would you play again?" + session length, and a fake-door creative test on the Surge clip for IPM/CPI.
- *What would make it wrong:* the Surge reads as chaotic/annoying rather than satisfying; escalation fatigues; tension feels stressful not exciting. All cheaply testable before scale.
- *Ethics check:* no dark patterns introduced. ✅
